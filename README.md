## 三、怎么把它跑起来

### 环境

| 项目 | 版本 / 说明 |
| --- | --- |
| Python | 3.13 |
| IDE | PyCharm Community Edition |

### 方法一：用 PyCharm 运行（推荐初学者）

1. 打开 PyCharm，菜单选 `File` → `Open`，选择这个文件夹（能看到 `HelloWorld.py` 的那一层）；
2. 在左侧文件列表里双击 `HelloWorld.py`，打开它；
3. 在代码任意位置点右键 → `Run 'HelloWorld'`（或者按 `Shift + F10`）；
4. 程序会在下方的 `Run` 窗口里跑起来。**需要输入时，先用鼠标点一下那个窗口，再打字、按回车** ——
   不点的话，你打的字会被别的窗口抢走，看起来就像程序卡住了。

### 方法二：用命令行运行（想更了解底层可以试）

在这个文件夹里打开终端，敲：

```bash
python HelloWorld.py
```

## 五、代码逐行看：`HelloWorld.py`

```python
print(1+1);
name=input()
name=input("please enter your name")
print(name,"welcome")
```

**运行后你会看到（第一次随便输点什么，比如「测试」；第二次输「杨训杰」）：**

```
2
测试
please enter your name杨训杰
杨训杰 welcome
```

> 注意第二行那个 `测试` —— 它**不是程序打印的**，是你自己敲进去的。
> 第三行里，`please enter your name` 是程序给的提示，后面的 `杨训杰` 是你敲进去的字，
> 两者接在同一条线上显示，回车之后才换行。

**逐行在干什么：**

| 行 | 干什么 | 说明 |
| --- | --- | --- |
| `print(1+1)` | 打印 `1+1` 的结果 | 括号里**可以直接写算式**，Python 会先算再打印，所以屏幕上出现的是 `2`，而不是 `1+1` |
| `name=input()` | 等键盘输入，把第一行内容存进 `name` | 这行**没写提示文字、结果后面也没用上**（下一行会把 `name` 重新赋值），是当初试「`input()` 到底能不能用」留下的痕迹 |
| `name=input("please enter your name")` | 先打印提示文字，再等键盘输入，把输入内容存进 `name` | 从这一行起，`name` 才是真正要用的值 |
| `print(name,"welcome")` | 打印 `name` 和 `welcome` | 用**逗号**隔开可以一次打印多个值，中间 Python 会自动补一个空格 |

**三个值得记住的点：**

1. **`input()` 拿到的一定是「文字」。**
   哪怕你输入 `18`，`name` 里装的也是文字 `"18"`，**不是数字 18**，所以它不能直接拿去算数。
   这一点和 Java 的 `Scanner.nextInt()` 正相反（那个读回来的就是数字），
   是 Python 新手最容易踩的坑 —— 以后要算数时会专门练它。

2. **`input()` 最好带上提示文字。**
   第二行那种「光秃秃的 `input()`」会让程序静静地等你打字，屏幕上什么都不显示，
   **看起来就像卡死了**。写成 `input("请输入你的名字：")` 就友善多了。

3. **Python 不需要分号 `;`。**
   第一行末尾那个 `;` 是从 Java 带过来的习惯。Python 里写了也能跑，
   但**不推荐** —— 正常的 Python 代码，一行就是一句话，不用结尾符号。
